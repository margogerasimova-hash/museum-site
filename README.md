# Сайт Software and Computer Museum

Сторінка про курси, екскурсію й експонати музею. З неї почнеться редизайн sncmuseum.org.
Вимоги описано в ТЗ («ТЗ — Сайт музею.docx»). Вигляд узято з макета «Прототип v4» і дизайн-системи на claude.ai.

## Файли

| Файл | Що в ньому |
|---|---|
| `index.html` | Українська сторінка |
| `contacts.html` | Сторінка «Як дістатися»: адреса, метро, графік роботи, телефон, посилання на маршрут |
| `courses.html` | Сторінка курсів: вибір за віком, опис кожного курсу, порівняння, запис |
| `en/index.html` | Англійська сторінка, переклад української |
| `en/courses.html` | Англійська сторінка курсів |
| `css/tokens.css` | Кольори, шрифти, відступи з дизайн-системи |
| `css/styles.css` | Вигляд сторінки й адаптація під телефон |
| `js/main.js` | Друк заголовка по літерах і меню на телефоні |
| `img/` | Логотип, фото першого екрана, фото вітрин, фото експонатів |
| `placeholder.html` | Заглушка «Сайт у розробці» |

Сайт статичний: без збирача й бібліотек. Шрифти завантажуються з Google Fonts.

## Як відкрити

Подвійний клік по `index.html` теж спрацює, але зручніше запустити локальний сервер:

```bash
python -m http.server 8080
```

Потім відкрийте http://localhost:8080.

## Як оновлювати

**Новини.** У блоці `<section id="news">` скопіюйте одну картку `<article class="card news-card">` і змініть дату й заголовок. Атрибут `datetime` пишіть як `РРРР-ММ-ДД`. Зробіть те саме в `en/index.html`.

**Експонати.** Покладіть квадратне фото приблизно 640 × 640 у `img/exhibits/` і скопіюйте одну картку `<article class="card exhibit lift">`. Обов’язково заповніть `alt`, тобто короткий опис фото словами.

**Шрифти чи кольори.** Змінюйте лише `css/tokens.css`: решта стилів бере значення звідти.

**Будь-який текст** змінюйте в обох файлах: `index.html` і `en/index.html`.

**Адреса, графік чи телефон** записані в трьох місцях: блок «Контакти» в `index.html`, сторінка `contacts.html` і підвал обох сторінок. Міняйте всюди, а також в `en/index.html`.

## Що ще не зроблено

- Вбудована карта: поки є блок із посиланням на маршрут у Google Maps (на головній і на `contacts.html`).
- Англійська версія `contacts.html`: зараз EN на цій сторінці веде на англійську головну.
- Адреси блогу, «Підтримай музей», соцмереж і юридичних документів у підвалі. Зараз там `href="#"`, у коді позначено коментарем.
- Логотип у SVG.
- Остаточні шрифти заголовків.
- Англійські тексти переклав Claude. Їх варто перечитати, особливо назви курсів і транслітерацію адреси.
